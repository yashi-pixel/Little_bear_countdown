# Little Bear Countdown

## Installation & Troubleshooting Guide

Little Bear Countdown is a web app that can be installed on your device like a regular app. You do not need to download it from an app store.

**Before you begin:** Make sure you have the published Little Bear Countdown website link.

---

# 1. Install on Windows

### Using Microsoft Edge

1. Open Microsoft Edge.
2. Visit the Little Bear Countdown website.
3. Click the **…** menu in the upper-right corner.
4. Select **Apps → Install this site as an app**.
5. Give the app a name if prompted, then click **Install**.
6. Launch Little Bear Countdown from the Windows Start menu.

### Using Google Chrome

1. Open Google Chrome.
2. Visit the Little Bear Countdown website.
3. Click the install icon in the address bar, if it appears.
4. Otherwise, click **⋮ → Cast, save, and share → Install page as app**.
5. Click **Install**.
6. Launch it from the Start menu or Chrome’s app launcher.

---

# 2. Install on Android

1. Open **Google Chrome** on your Android phone.
2. Visit the Little Bear Countdown website.
3. Tap the **⋮** menu.
4. Tap **Install app** or **Add to Home screen**.
5. If prompted, choose **Install**.
6. Find the Little Bear Countdown icon on your home screen or in your app list.

**Tip:** If it opens with Chrome’s address bar, it may have been added as a shortcut instead of installed. Try opening the website in Chrome again and selecting **Install app**.

---

# 3. Install on Mac

### Using Google Chrome

1. Open Google Chrome.
2. Visit the Little Bear Countdown website.
3. Click the install icon in the address bar, if available.
4. Otherwise, click **⋮ → Cast, save, and share → Install page as app**.
5. Click **Install**.
6. Open Little Bear Countdown from the app launcher or Applications, if offered.

### Using Microsoft Edge

1. Open Microsoft Edge.
2. Visit the Little Bear Countdown website.
3. Click **… → Apps → Install this site as an app**.
4. Click **Install**.

---

# 4. Install on iPhone or iPad

Use **Safari** for installation.

1. Open Safari.
2. Visit the Little Bear Countdown website.
3. Tap the **Share** button.
4. Scroll down and tap **Add to Home Screen**.
5. Edit the app name if desired.
6. Tap **Add**.

The Little Bear Countdown icon will appear on your Home Screen.

---

# 5. Troubleshooting and Reinstalling

## The app opens as a webpage with browser controls

It may have been added as a shortcut instead of installed as an app.

* **Windows/Mac:** Open the site in Edge or Chrome and use the browser’s **Install this site as an app** option.
* **Android:** Open the site in Chrome and choose **Install app**.
* **iPhone/iPad:** Install through Safari using **Share → Add to Home Screen**.

## The app shows an old version after an update

1. Close the app completely.
2. Open the website in the browser.
3. Refresh the page:

   * Windows: **Ctrl + Shift + R**
   * Mac: **Cmd + Shift + R**
   * Android/iPhone: Refresh the page in the browser.
4. Reopen the installed app.

If it still shows the old version, clear the website’s cached files or service worker, then reopen it.

**Important:** Avoid clearing all site data or browser storage unless necessary. Your countdown dates may be stored locally, and clearing that data can erase them.

## The app icon is missing or won’t open

1. Remove the existing home-screen icon or installed app.
2. Open the published website in the recommended browser.
3. Install it again using the steps above.

## The app is blank or not loading

1. Check your internet connection.
2. Open the website directly in your browser.
3. Refresh the page.
4. If the website itself is unavailable, check that GitHub Pages is still enabled in the repository’s **Settings → Pages**.

---

# 6. Will updates require reinstalling?

**Usually, no.**

When the app is updated on its published website:

* The installed app keeps the same icon and installation.
* **The new version should load automatically or after a refresh/reopen.**
* You generally do not need to uninstall and reinstall it.

If an update does not appear, close and reopen the app, then refresh the website in the browser. Reinstall only if the app remains broken after refreshing and clearing its cached files.

**FYA,** Your countdown dates are saved locally on each device and browser. They do not automatically sync across devices.
